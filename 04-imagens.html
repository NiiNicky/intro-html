Trabalhando com o elemento de <img>

Entendendo os atributos

  • srcSource/fonte: É o caminho onde a imagem está hospedada/armazenada. Pode ser um caminho local ou um link direto da internet.
  • altAlta/alternative: É uma breve descrição da imagem. É crucial para aacessibilidadee como fallback(plano B).

Sobre os tipos de imagens

Você pode encontrar um acervo muito grande de tipos de imagens, a escolha da imagem correta pode elevar a performace do seu site. Veja a lista abaixo:

  • JPEG/JPG: Bom para fotografias, produtos fotografadosimagens com muitas cores e detalhes. Se você tentar otimizar demais, a perda de qualidade se torna vísivel.
  • PNG: Suporta tranparência e é muito bom para imagens que precisam preservar certos detalhes. Por exemplo: logos, imagens que precisam de transparência e etc.
  • WEBP: Formato recente desenvolvido com foco na web. Além de tambem suportar transparência, também consegue trabalhar com imagens em alta definição. Exelente escolha para fotografias, imagens de produtos, imagens com transparéncia e imagens geraís.
  • WEBP: É formato mais recente e também muito eficiente. É exelente, para fotopgrafias, imagens grandes, sites onde desempenho e economia de dados são extremamente importantes.
  • SVG: É um elemneto vetorial, exelente para logos, icones, simbolos e etc.
